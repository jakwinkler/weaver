## How to read these guides

The invited-client guide contains only client actions. Other feature guides start with the everyday steps, then use **Technical reference (developers and LLMs)** for API, source, and operational detail. You can stop before that section if you only need to use Weaver.

Original screenshots show a local installation with the fictional **Northstar Studio / Website Launch** workspace. The client guide uses newer disposable client fixtures. Names, issues, dates, and requests are examples. They are not customer records. Click an image to inspect it at full size.

## What this documentation describes

The original feature walkthrough and screenshots describe main at `1b1b370`, checked September 23, 2026. The October 15, 2026 pilot update checks invited-client access, issues/comments, board persistence, plugin gates, and current sign-in/deployment paths against `ce5494a`. Each guide keeps its own source and verification notes. Your installation can differ by deployed revision, plugins, and permissions.

The client guide and issue creation instructions also include the local inline help implementation that follows that pilot release. Its verification is recorded in [Feature Coverage](https://github.com/jakwinkler/weaver/wiki/Feature-Coverage); those UI changes still need deployment.

The source roadmap contains planning history and stale checkboxes. [Feature Coverage](https://github.com/jakwinkler/weaver/wiki/Feature-Coverage) maps all 30 roadmap items to these guides and records what was checked. It also identifies external integrations and native-app behavior that were not verified in this documentation walkthrough.

This GitHub wiki documents Weaver itself. The [Wiki inside a Weaver project](https://github.com/jakwinkler/weaver/wiki/Project-Wiki) is where your team writes its own project documentation.
